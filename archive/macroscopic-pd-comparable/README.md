# Superseded comparable-rate Poisson–Dirichlet manuscript

This directory preserves the 21-page audited comparable-rate predecessor, its source, and its extraction map exactly as they appeared at repository commit `40afaebb02e176b5262650edb0ad23ac7e986699`. Their hashes are recorded in [the preservation manifest](../manifest.json). These files are immutable provenance, excluded from the active manuscript catalog and deterministic rebuilds.

The canonical successor is [Spectral Poisson–Dirichlet Universality for Luce Permutations under Arbitrary Rate Arrangements](../../papers/macroscopic-pd/spectral-poisson-dirichlet-luce.tex), registered under the stable catalog ID `macroscopic-pd`. It includes the comparable-rate result and extends the macroscopic cycle theorem to its full spectral criterion, including every assignment of the Sukhatme rate multiset to labels.

The historical [extraction record](../../audits/macroscopic-pd-extraction.md), [proof audit](../../audits/macroscopic-pd-proof-audit.md), and [repair record](../../audits/macroscopic-pd-repair-record.md) describe this predecessor. Its extraction and repair checks now run against the preserved files here. The [spectral migration map](../../papers/macroscopic-pd/THEOREM_MIGRATION.md) records the correspondence with the active source.
